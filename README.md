# 🤖 Rule-Based AI Chatbot

A simple yet interactive **Rule-Based AI Chatbot** built using Python.  
This project demonstrates the fundamentals of **Artificial Intelligence concepts**, **decision-making logic**, and **control flow** using conditional statements and loops.

---

## 📌 Project Overview

The chatbot responds to predefined user inputs using **if-else logic** and runs continuously until the user exits the conversation.

This beginner-friendly AI project helps in understanding:
- Rule-based systems
- User interaction handling
- Conditional decision-making
- Continuous program execution

---

## 🚀 Features

✅ Handles greetings like:
- Hello
- Hi
- Hey

✅ Responds to basic conversations

✅ Handles exit commands:
- Bye
- Exit
- Quit

✅ Uses:
- `if-else` conditions
- Infinite loops (`while`)
- String matching

✅ Beginner-friendly and easy to customize

## ⚙️ How It Works

The chatbot:
1. Takes input from the user
2. Converts input into lowercase
3. Checks predefined conditions
4. Returns matching responses
5. Continues the conversation until the user exits

---

## 💻 Sample Conversation

```bash
You: hello
Bot: Hi! How can I help you today?

You: how are you
Bot: I'm doing great! Thanks for asking.
```
