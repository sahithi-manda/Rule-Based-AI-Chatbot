# Rule-Based AI Chatbot

A rule-based AI chatbot GUI built using Python and Tkinter.

## Features
- GUI-based chatbot interface
- Rule-based intent recognition
- Deterministic chatbot responses
- State/history tracking
- User input sanitization
- Interactive conversation flow

## Technologies Used
- Python
- Tkinter

## Project Structure
Rule-Based-AI-Chatbot/
│
├── chatbot.py
└── README.md

## How to Run

1. Install Python
2. Run the following command:

python chatbot.py

## Sample Intents
- Greetings
- Identity questions
- Joke requests
- Weather requests
- Help commands
- Exit commands
